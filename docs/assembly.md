# Assembly

选定打样版本后，从同一个 GitHub Release 获取底板生产包和底座打印文件，并核对 PCB 修订号和底座版本。

整机物料包括六块 MCI 845 核心板、140 × 65 mm 集群底板、打印托盘、可拆风扇面板，以及台达 AFC0712DD-TP10 70 × 70 × 20 mm 风扇。当前打印文件、紧固件规格和安装顺序见 [Printed Base](../hardware/enclosure/printed-base/README.md)。PCB 贴片 BOM 由嘉立创 EDA 工程导出。

安装顺序及连接器方向以对应版本的装配图为准。装好后按[上电调试](bringup.md)逐槽检查。
